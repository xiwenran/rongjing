## V3.8 — 独立「图片去水印」Tab（2026-05-25）

启动日期：2026-05-25
背景：用户日常会用豆包 / OpenAI / Midjourney 等外部 AI 生成图片作为笔记封面或素材，目前工作流是用拼图页 1×1 单格当去水印工具——这是 hack 用法，入口隐蔽、操作绕弯、效果还受差异化开关影响。本期新增独立 Tab，专门做这件事。前置审计结论：当前对 OpenAI 生成图的 C2PA/EXIF 已主动剥离，但像素级暗水印（如 SynthID）只靠透视变换"顺带破坏"、无显式保证；本期把它做成显式步骤。

### V3.8-A: 独立 Tab "图片去水印"
- 目标：左侧导航新增 🛡️ "去水印"入口，提供轻/中/强三档强度的批量去水印处理
- 涉及文件：
  - `core/dewatermark.py`（新增，核心处理）
  - `ui/dewatermark_tab.py`（新增，UI）
  - `ui/main_window.py`（修改，导航集成）
- UX：选图（文件夹 / 多选 / 拖拽）→ 选强度 → 选输出目录 → 一键导出
- 三档强度：
  - **轻**：剥元数据（C2PA/EXIF/XMP），像素值保持
  - **中**：剥元数据 + 轻微 resize 来回 + 重编码（破坏多数像素水印）
  - **强**：剥元数据 + resize + 微噪声 + 颜色微抖动 + 重编码（破坏 SynthID 等顽固水印）
- 关键约束（零回归）：
  - 不动 BatchRunner / VideoRunner / CollageBatchRunner 任何逻辑
  - 不影响现有 4 个 Tab（模板配置/批量导出/拼图/AI 背景）的导航和样式
  - 主题色、按钮风格、卡片样式保持与现有 UI 一致
- 验收标准（机械可测）：
  - 启动 app，左侧能看到"去水印" Tab
  - 选 5 张测试图 + 中档 + 输出目录 → 输出目录有 5 张图
  - 输出图用 `exiftool` 检查：无 EXIF / C2PA / XMP
  - 中档输出与原图像素值不同（`np.array_equal` 返回 False）
  - 强档输出有微噪声但视觉无明显差异（PSNR ≥ 30dB）
- 实测结果：三档处理符合预期、元数据全空、强档 PSNR 37.7dB；现有 4 个 Tab 零回归
- 冷眼审查发现的输入/输出同路径静默覆盖原图 bug 已本次一并修复（自动加 `_clean` 后缀）
- 状态：✅ 已完成（2026-05-25，commit 08f9360，冷眼审查 6/8 通过 + 1 真实 bug 已修 + 1 体验问题作为发现项跟进）
